# Sang-se-Style Benchmark Reference Map

English counterpart for `references/sangse-style-benchmark.ko.md`. Use this file to understand what may be benchmarked, then read the Korean original for the full checklist.

## Benchmarkable Patterns

Use the public Sang-se-style experience only as an operating-pattern benchmark:

- fast three-step input flow
- separate category and style template selection
- reusable block-library structure
- editable Figma text layers for Korean copy, tables, notices, FAQ, prices, and options
- brand color and visual-token application
- optional extra proof, FAQ, review, option, or motion/GIF candidate blocks
- export-ready production structure

## Do Not Copy

Do not copy Sang-se branding, logo, characters, benefit copy, pricing cards, UI trade dress, public sample images, or templates. Do not target a near-identical screen. The goal is a new Korean commerce detail-page production workflow that is easy to edit in Figma.

## Production Checklist

Confirm assumptions when inputs are sparse, choose category and visual tone separately, include category-specific proof and compliance needs, keep editable text out of generated raster imagery, record design tokens, separate representative images from body cuts, mark optional motion candidates, and leave legal/platform/rights risks in `platform-checklist.md`.
