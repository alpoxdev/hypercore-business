# Research Findings Reference Map

English counterpart for `references/research-findings.ko.md`. Use this as an English summary of the baseline research, then read the Korean original for source URLs, Korean wording, and category-specific source notes.

## Baseline Research

The baseline research file is `.hypercore/research/2026-04-29-product-detail-maker-skill-research.md`.

Key conclusions:

- Korean product detail pages commonly use image-led sections and practical 860px-wide mobile-readable production patterns.
- SmartStore representative and additional images have separate practical requirements from long detail-body imagery.
- SmartEditorONE can constrain long descriptions and external/scripted content, so section splitting and platform checks matter.
- Korean product information notices must be included as seller-facing production checks, not treated as legal approval.
- Cafe24 Edibot-style tools show that category recognition, product information templates, and auto layout are important precedents.
- Korean reference work should combine platform help centers, domestic seller tools, agency/operator materials, and actual marketplace patterns.

## Sang-se, Figma, and Category Update

The update file is `.hypercore/research/2026-05-02-sangse-figma-category-detail-page-skill-research.md`.

Key conclusions:

- Benchmark Sang-se-style operating patterns: fast input, category/style template selection, reusable blocks, editable Figma layers, and export readiness.
- Do not copy Sang-se branding, characters, copy, sample images, UI trade dress, or templates.
- Select a category playbook before finalizing section order, claims, proof, and image direction.
- Regulated categories need explicit claim guards and seller verification.

## Reuse Rule

For generic requests, reuse the baseline plus the Sang-se/Figma/category update. For specific categories, add fresh Korean/category sources before final factual claims, regulated wording, or image direction.
