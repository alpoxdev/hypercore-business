# 상세뚝딱(Sang-se)형 벤치마크 가이드

Baseline report: `.hypercore/research/2026-05-02-sangse-figma-category-detail-page-skill-research.md`

이 파일은 `https://www.sang-se.com/` 공개 페이지에서 관찰한 **운영 패턴**을 상세페이지 제작 스킬에 반영하기 위한 가이드다. 목적은 유사한 제작 경험과 산출 품질을 만드는 것이며, 상세뚝딱의 로고, 캐릭터, 문구, 샘플 이미지, UI 트레이드드레스, 템플릿을 복제하는 것이 아니다.

## 벤치마크할 핵심 패턴

- **3단계 입력 흐름**: 제품/카테고리/보유 사진/핵심 장점 입력 → 카테고리·스타일 템플릿 선택 → 생성/수정.
- **카테고리 + 스타일 템플릿**: 제품군(뷰티, 식품, 패션, 생활, 전자 등)과 톤(심플한, 기능성, 프리미엄, 로맨틱, 화려한 등)을 분리해 선택한다.
- **블록 라이브러리형 상세페이지**: Hero, Pain, Benefit, Proof, Usage, Detail, Options, FAQ, Policy, Product Notice를 재사용 가능한 섹션 블록처럼 설계한다.
- **Figma 기반 수정 가능성**: 긴 한국어 카피, 표, 고시정보, 가격, 옵션, FAQ는 래스터 이미지가 아니라 editable text layer로 둔다.
- **브랜드 자동 적용**: 브랜드 컬러, 폰트 분위기, 배경 질감, 라운드, 아이콘 스타일을 디자인 토큰으로 정리해 전체 프레임에 반영한다.
- **추가 섹션 삽입**: 제품 정보가 부족하거나 전환 설득이 약하면 추가 proof/review/FAQ/option block을 끼워 넣을 수 있게 만든다.
- **움직임/GIF 후보**: 실제 GIF를 만들지 않더라도 “움직이면 설득력이 생기는 컷”을 별도 표시한다. 예: 사용 전후, 접힘/펼침, 조립, 발림성, 수납.
- **다국어 확장 가능성**: 기본은 한국어지만, 텍스트 레이어와 구조를 분리해 향후 번역하기 쉽게 만든다.

## 절대 복제하지 말 것

요약: 참고 가능한 것은 제작 패턴이며, 상세뚝딱 고유 자산은 복제하지 않는다.

- 상세뚝딱 브랜드명, 로고, 캐릭터, 혜택 문구, 가격 카드, UI 레이아웃을 그대로 사용하지 않는다.
- 공개 샘플 이미지를 재사용하거나 비슷하게 생성하라고 지시하지 않는다.
- “거의 동일한 화면”을 목표로 하지 않는다. 목표는 **Figma에서 쉽게 수정 가능한 한국형 상세페이지 생성 경험**이다.
- 사이트의 문장 구조를 그대로 가져오지 말고 제품/카테고리에 맞는 새 한국어 카피를 작성한다.

## Sang-se-inspired production checklist

작업 중 다음 항목을 모두 확인한다:

1. 입력값이 부족해도 가정 로그로 시작했는가?
2. 제품 카테고리와 디자인 톤을 별도로 선택했는가?
3. 카테고리별 필수 정보/증거/주의 문구가 섹션에 반영되었는가?
4. Figma에서 수정해야 할 텍스트를 이미지에 굽지 않았는가?
5. 브랜드 컬러/폰트/컴포넌트 토큰이 `figma-frame-spec.json` 또는 Figma layer에 기록되었는가?
6. 대표 이미지와 본문 상세컷의 플랫폼 기준을 분리했는가?
7. 추가 블록 후보와 GIF/모션 후보를 표시했는가?
8. 법적·플랫폼·권리 리스크를 `platform-checklist.md`에 남겼는가?
