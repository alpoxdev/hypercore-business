# Korean Platform and Compliance Checks

This is a production checklist, not legal advice.

## SmartStore checks

- Representative/additional images: check the 1000 x 1000 px recommendation and allowed static image file types for product images.
- Detail body: avoid a single very long image; split mobile-readable sections.
- Detail length: account for SmartEditor display behavior where long content may collapse behind an expand/collapse detail-information control.
- Links/scripts: avoid unsupported external links, scripts, or tags in SmartEditor/HTML contexts.
- If SmartStore and Shopping Window differ, use the stricter channel review standard.

## Cafe24 / own mall checks

- Use category-appropriate templates and product information fields.
- Preserve editable text where SEO, translation, accessibility, or future edits matter.
- Check responsive rendering, loading weight, image alt text, and page speed.
- If using AI-generated model/lifestyle images, keep product proportions and usage truthful.

## Gmarket/Auction/open-market image checks

- Main product image should show the same product being sold.
- Avoid unauthorized celebrity, copyrighted, or misleading imagery.
- Check file size, file type, and minimum dimension requirements for the target market.
- Avoid option image/price mismatches.

## Korean product information notice checks

Include or request seller-provided facts for:

- Product name/model, manufacturer/importer/seller, country of origin
- Material/ingredient/specification, size/weight/capacity, components
- Manufacturing date, expiration/use-by date, quality guarantee where relevant
- KC/certification/safety information where relevant
- Caution, storage/handling, age restrictions, allergy/ingredient warnings where relevant
- A/S responsible party and contact
- Shipping, exchange, return, refund, and customer service policy

## Claim safety

Mark these as seller verification required unless evidence is supplied:

- No.1, best, guaranteed, official, clinical, patented, certified, hypoallergenic
- Before/after performance claims
- Medical, health, diet, cosmetic efficacy claims
- Review counts/ratings and influencer endorsements
- Origin, handmade, organic, eco-friendly, vegan, cruelty-free

## Final preflight

- Mobile readability: headline visible without zoom; body text not too dense.
- Image weight: split and compress large sections.
- Text accuracy: all Korean visible text is editable or manually proofread.
- Evidence: factual claims have source, product proof, or seller-verification-required marker.
- Rights: all photos, models, icons, fonts, templates, and generated assets are usable for commerce.
