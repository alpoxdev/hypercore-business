# 한국 플랫폼 및 컴플라이언스 체크

이 문서는 제작 체크리스트이며 법률 자문이 아니다.

## SmartStore 체크

- 대표/추가 이미지: 상품 이미지 1000×1000px 권장과 허용 정지 이미지 형식을 확인한다.
- 상세 본문: 너무 긴 단일 이미지를 피하고 모바일에서 읽기 쉬운 섹션으로 분할한다.
- 상세 길이: 긴 콘텐츠가 `상세정보 펼쳐보기/접기` 뒤로 접힐 수 있는 SmartEditor 표시 방식을 고려한다.
- 링크/스크립트: SmartEditor/HTML 문맥에서 지원되지 않는 외부 링크, 스크립트, 태그를 피한다.
- SmartStore와 Shopping Window 기준이 다르면 더 엄격한 채널 검수 기준을 따른다.

## Cafe24 / 자사몰 체크

- 카테고리에 맞는 템플릿과 상품 정보 필드를 사용한다.
- SEO, 번역, 접근성, 추후 수정이 중요한 텍스트는 editable text로 보존한다.
- 반응형 렌더링, 로딩 무게, 이미지 alt 텍스트, 페이지 속도를 확인한다.
- AI 생성 모델컷/라이프스타일컷을 사용할 때 제품 비율과 사용 맥락을 사실적으로 유지한다.

## Gmarket/Auction/오픈마켓 이미지 체크

- 메인 상품 이미지는 실제 판매 상품과 동일해야 한다.
- 무단 연예인 이미지, 저작권 침해 이미지, 오해를 부르는 이미지를 피한다.
- 대상 마켓의 파일 크기, 파일 형식, 최소 해상도 요구사항을 확인한다.
- 옵션 이미지와 가격/구성의 불일치를 피한다.

## 상품정보제공고시 체크

다음 정보는 포함하거나 판매자에게 요청한다:

- 제품명/모델명, 제조자/수입자/판매자, 원산지
- 소재/성분/사양, 크기/무게/용량, 구성품
- 제조일자, 유통기한/사용기한, 관련 품질보증 정보
- KC/인증/안전 정보가 필요한 경우 해당 정보
- 주의사항, 보관/취급 방법, 연령 제한, 알레르기/성분 경고
- A/S 책임자와 연락처
- 배송, 교환, 반품, 환불, 고객센터 정책

## 주장 안전성

다음 표현은 증거가 제공되지 않으면 `확인 필요`로 표시한다:

- No.1, 최고, 보장, 공식, 임상, 특허, 인증, 저자극
- 전후 비교 성능 주장
- 의료, 건강, 다이어트, 화장품 효능 주장
- 리뷰 수/평점, 인플루언서 보증
- 원산지, 수제, 유기농, 친환경, 비건, 크루얼티프리

## 최종 프리플라이트

- 모바일 가독성: 확대하지 않아도 헤드라인이 보이고 본문이 과밀하지 않다.
- 이미지 무게: 큰 섹션은 분할하고 압축한다.
- 텍스트 정확성: 모든 한국어 표시 문구는 editable 상태이거나 수동 검수되었다.
- 근거: 사실 주장은 출처, 제품 증빙, 또는 `확인 필요` 표시 중 하나를 갖는다.
- 권리: 사진, 모델, 아이콘, 폰트, 템플릿, 생성 이미지가 커머스 사용에 문제가 없다.
